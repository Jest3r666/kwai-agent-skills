# kwai-deploy-guard

发布巡检速查。核心流程:环境检查 → 依赖复核 → 配置核对 → 回滚预案。

## 1. 环境检查

```bash
bash scripts/probe.sh deploy-guard
```

不可达时按输出提示使用容灾入口(办公区外场景),见 `docs/FAQ.md`。

## 2. 依赖复核

- 逐个确认下游依赖服务的近期错误率与 P99 时延
- 依赖变更公告核对:发布窗口内下游是否有变更/维护
- 本次发布涉及的服务清单与依赖树打印出来人工过一遍

## 3. 配置核对

- 配置基线:`config/` 下资源与配置中心逐项 diff(环境差异、灰度开关)
- 新增配置项必须带默认值,避免空值导致启动失败
- 数据库变更(DDL)先评审再随发布执行

## 4. 回滚预案

- 回滚粒度:整包回滚优先,单点回滚兜底
- 准备:上一版本镜像 tag、回滚命令、影响评估(预计影响时长)
- 结论输出 Go / No-Go + 风险项 + 回滚窗口建议,落盘 `docs/release-guard-YYYYMMDD.md`

## 5. 发布后验证

- 发布后 10 分钟观察:错误率、P99、告警
- 增量灰度:1% → 10% → 50% → 全量,每档观察 5 分钟
